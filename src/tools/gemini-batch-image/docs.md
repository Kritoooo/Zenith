# Gemini 批量生图

选一个包含图片的文件夹，用 Gemini 图像模型（Nano Banana）把同一条 prompt 应用到每一张图，全部在浏览器里完成。

## 功能
- 支持整文件夹拖拽或文件选择器上传，也可另外追加单张图片。
- 所有队列中的图片共用一条 prompt。
- 并发可选 1–4，Stop 按钮会通过 `AbortSignal` 真正取消正在进行的请求。
- 每张图都有独立状态、单独重试，以及单独下载。
- 批量下载 ZIP 由 Web Worker 完成，不引入额外依赖。
- 输出文件名 = 原文件名 + 后缀（默认 `-gemini`）+ `.png`，不同子目录的同名文件会自动避免冲突。

## 使用步骤
1. 粘贴 Gemini API Key；勾选“在本机记住”会写入 `localStorage`，否则仅保存在当前会话。
2. 拖入一个文件夹（或点击选择）。仅 JPEG / PNG / WebP 会进入队列，其他格式会被标记为 Skipped。
3. 填写要应用给每张图的 prompt，按需调整文件名后缀与并发数。
4. 点击 **开始**，观察每张图的状态；可随时按 **停止** 取消。
5. 使用 **下载 ZIP** 一键打包，或单张下载。

## 说明
- API Key 由浏览器直接发送到所配置的接口，不会经过 Zenith 的后端。
- **自定义 Base URL** 留空则走 Google 官方 `generativelanguage.googleapis.com`；也可填入任何兼容 Gemini 协议的接入点（如 `https://api.grsai.ai`），此时请搭配该服务商签发的 API Key。
- Gemini 可能拒绝某些 prompt 或图片，会显示错误并可单独重试。
- 结果总体积超过约 150 MB 时会提示，建议改用“逐个下载”以避免 ZIP 打包缓慢。
- 取消只中断客户端请求，Google 仍可能对已在进行中的调用计费。
