# 做 T 计算器

先卖后买的日内做 T（正 T）测算。输入卖出份额与卖出价格，得到保本买回价，以及达到目标收益率或目标金额所需的买回价。

## 功能
- 按 A 股默认费率计算卖出净收入与费用明细
- 首版限制卖出份额为 100 股（1 手）的整数倍
- 保本价，以及 0.3% / 0.5% / 1% / 1.5% / 2% / 3% 目标买回价
- 自定义目标：按收益率或按金额
- 佣金费率、最低佣金、印花税、过户费、最小价格变动均可自定义，并保存在本地浏览器

## 使用步骤
1. 输入卖出份额与卖出价格；卖出份额必须为 100 股的整数倍。
2. 若与自己券商的费率不同，在「费率设置」中调整；设置会自动保存在本地。
3. 在表格中查看各目标对应的买回价、需跌幅、买回成本、净盈亏与实际收益率。
4. 需要其他目标时，用「自定义」按收益率（%）或按金额（元）输入。

## 计算方式
- 卖出费用 = max(卖出金额 × 佣金费率, 最低佣金) + 卖出金额 × 印花税 + 卖出金额 × 过户费
- 卖出净收入 = 卖出金额 − 卖出费用
- 买回成本 = 买回金额 + max(买回金额 × 佣金费率, 最低佣金) + 买回金额 × 过户费
- 净盈亏 = 卖出净收入 − 买回成本
- 收益率 = 净盈亏 ÷ 卖出金额
- 目标买回价由「买回成本 = 卖出净收入 − 目标盈亏」反解得到，并按最小价格变动向下取整，因此实际盈亏不低于目标；表格小字为未取整的精确解。

## 默认费率（A 股）
| 项目 | 默认值 | 收取方向 |
| --- | --- | --- |
| 佣金 | 0.025%，单笔最低 5 元 | 买入 + 卖出 |
| 印花税 | 0.05% | 仅卖出 |
| 过户费 | 0.001% | 买入 + 卖出 |
| 最小价格变动 | 0.01 元 | — |

## 注意
- 默认值为常见档位，实际费率以券商合同为准。规费（经手费、证管费）通常已包含在佣金里，若券商单独收取，可相应调高佣金费率。
- 场内基金 / ETF 不收印花税，可将印花税设为 0；最小价格变动通常为 0.001 元。
- 未考虑涨跌停限制。若所需跌幅超过当日涨跌幅限制（主板 10%、创业板与科创板 20%、北交所 30%），当天无法成交。
- 首版要求卖出份额为 100 股（1 手）的整数倍，并按相同份额计算买回；科创板等市场的特殊申报数量规则暂未单独建模。
- 结果为理论测算，未包含分红送转、融资融券利息、分笔成交与四舍五入等因素，仅供参考，不构成投资建议。
