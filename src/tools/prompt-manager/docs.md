# Prompt 管理器

用于整理可复用 Prompt 模板、填充变量并生成可直接复制的输出。

## 功能
- 管理 Prompt 条目（新建、复制、删除）
- 支持置顶常用 Prompt（列表优先显示）
- 添加标签并按标签筛选
- 识别 `{{变量名}}` 格式变量
- 填写变量并实时预览渲染结果
- 按 Prompt 记录历史快照并可一键恢复
- 通过 JSON 导入/导出 Prompt 库

## 使用步骤
1. 点击 `新建` 添加 Prompt。
2. 在编辑区填写标题、标签和内容。
3. 使用 `{{name}}` 写变量，在变量面板填写值。
4. 按需复制原始 Prompt 或渲染预览。
5. 使用 `导入` / `导出` 在设备间迁移模板。

## 注意
- 数据保存在浏览器本地存储。
- 未填写值的变量占位符会被保留。
- 导入支持 Prompt 数组，或包含 `prompts` 字段的对象。
