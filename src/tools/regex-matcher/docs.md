# Regex Matcher

快速校验正则表达式，并复用常用匹配模板。

## 功能
- 字段模式支持列表编辑与文本模式切换
- 默认输出为每行一条记录、字段用逗号分隔
- 可启用脚本自定义输出格式
- 预设 URL、邮箱、IPv4、日期、十六进制颜色与 UUID
- 支持 JavaScript RegExp 标志位（g, i, m, s, u）

## 使用步骤
1. 在字段模式中添加字段（列表）或切换到文本模式（`字段名,正则`）。
2. 根据需求勾选标志位。
3. 在输入框粘贴文本查看匹配结果。
4. 需要自定义输出时开启脚本。

## 注意
- 正则使用 JavaScript RegExp 语法，无需 `/ /` 包裹。
- 未启用全局标志时，每个字段只返回第一条匹配。
- 为性能考虑，最多展示 200 条结果。
